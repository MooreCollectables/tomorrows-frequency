Privacy Policy

Last updated: 4 November 2026

This policy covers the Tomorrows Frequency website and Channel Uploader, the private tool the Tomorrows Frequency channel uses to publish its own videos through YouTube API Services.

Who uses Channel Uploader

Channel Uploader is an internal tool. It is used only by the owner of the Tomorrows Frequency YouTube channel, on their own computer, to manage that one channel. It is not available to the public, and it cannot be used to sign in to or access anyone else's YouTube account.

YouTube API Services

Channel Uploader uses YouTube API Services. By using it, the channel owner is bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed

With the channel owner's permission (Google OAuth), Channel Uploader accesses only the Tomorrows Frequency channel, to:

  • upload videos created for the channel, with their titles, descriptions, tags, thumbnails and privacy settings;
  • create and update the channel's own playlists and add the channel's videos to them;
  • read the channel's own playlists and video details, so it can avoid duplicates.

It does not read, collect or store data about viewers, subscribers, commenters or any other YouTube user.

How data is stored

The OAuth access token that Google issues is stored only in a local file on the channel owner's computer, and is never sent anywhere except to Google's own servers when calling the YouTube API. Video files and their metadata are created and stored locally by the channel owner. No data is sold, shared with third parties, or used for advertising.

Cookies and this website

This website is a static page hosted on GitHub Pages. It sets no cookies and runs no analytics or tracking. GitHub may keep standard server logs, as described in GitHub's privacy statement.

Revoking access

Access granted to Channel Uploader can be revoked at any time on the Google security settings page: security.google.com/settings/security/permissions. Deleting the local token file also removes the tool's access.

Data deletion

Channel Uploader keeps no copies of YouTube data beyond the channel's own video and playlist IDs, which are stored locally. They are deleted when the files are deleted or when access is revoked, and at the latest within 30 days of revocation.

Changes

If this policy changes, the updated version will be posted on this page with a new date.
